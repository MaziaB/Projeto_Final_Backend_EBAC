Projeto Final Backend EBAC - API de comunicação com a PokeAPI 

Objetivo: Construir uma API que se alimente com as informações de pokemons da PokeAPI. Através desse projeto, vamos fixar os conceitos e etapas da construção do backend de uma aplicação web com Python.

Linguagem e Tecnologias:
Python
FastAPI
Pydantic
SQLalchemy;
SQLite;
Redis;
Docker;
Pytest;
Render;
GitHub Actions;
